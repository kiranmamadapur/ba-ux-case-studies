# QuickBite: User stories and acceptance criteria

> **Concept project.** Independent case study created to demonstrate BA and UI/UX method. The client, users and data are fictional, and the KPI baselines and targets are assumptions. Nothing here is client work.

[← All case studies](../README.md)

## US-01

As a customer, I want to see a true arrival time, so that I plan my evening.

**Acceptance criteria**

- **Given** a rider is assigned
- **When** I open tracking
- **Then** the map and arrival time update

## US-02

As a restaurant, I want to see a clear order queue, so that I do not miss orders.

**Acceptance criteria**

- **Given** a new order
- **When** the tablet is open
- **Then** it sounds an alert and shows items

## US-03

As a manager, I want to see delivery KPIs, so that I fix delays.

**Acceptance criteria**

- **Given** a day of orders
- **Then** the dashboard shows average order-to-door time
