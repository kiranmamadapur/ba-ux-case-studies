# MediCare Plus: User stories and acceptance criteria

> **Concept project.** Independent case study created to demonstrate BA and UI/UX method. The client, users and data are fictional, and the KPI baselines and targets are assumptions. Nothing here is client work.

[← All case studies](../README.md)

## US-01

As a patient, I want to book a slot online, so that I avoid phoning the clinic.

**Acceptance criteria**

- **Given** an open slot
- **When** I book it
- **Then** it disappears for other patients

## US-02

As a receptionist, I want to see one shared calendar, so that I never double book.

**Acceptance criteria**

- **Given** a booked slot
- **When** staff open the calendar
- **Then** they see it with the patient name

## US-03

As a doctor, I want to see my day list in order, so that I plan my time.

**Acceptance criteria**

- **Given** a visit tomorrow
- **Then** a reminder is sent 24 hours before
