# UrbanThread: User stories and acceptance criteria

> **Concept project.** Independent case study created to demonstrate BA and UI/UX method. The client, users and data are fictional, and the KPI baselines and targets are assumptions. Nothing here is client work.

[← All case studies](../README.md)

## US-01

As a shopper, I want to filter by size and price together, so that I find items quickly.

**Acceptance criteria**

- **Given** two filters
- **When** I tap Apply
- **Then** results update and the count shows

## US-02

As a shopper, I want to check out as a guest, so that I do not need an account.

**Acceptance criteria**

- **Given** no account
- **When** I reach payment
- **Then** I can complete the order with an email only

## US-03

As a shopper, I want to track my order, so that I know when it arrives.

**Acceptance criteria**

- **Given** a shipped order
- **When** I open tracking
- **Then** each status step shows its date
