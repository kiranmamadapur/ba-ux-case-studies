# NovaBank: User stories and acceptance criteria

> **Concept project.** Independent case study created to demonstrate BA and UI/UX method. The client, users and data are fictional, and the KPI baselines and targets are assumptions. Nothing here is client work.

[← All case studies](../README.md)

## US-01

As a customer, I want to save a beneficiary, so that I do not retype details.

**Acceptance criteria**

- **Given** a valid account number
- **When** I save it
- **Then** the name is shown for confirmation

## US-02

As a customer, I want to see a clear confirmation, so that I trust the transfer went through.

**Acceptance criteria**

- **Given** an amount above my limit
- **When** I continue
- **Then** I see the limit and an option to change

## US-03

As a customer, I want to search past transactions, so that I find a payment fast.

**Acceptance criteria**

- **Given** a keyword
- **When** I search
- **Then** matching transactions show newest first
