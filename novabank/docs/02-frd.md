# NovaBank: Functional requirements (FRD)

> **Concept project.** Independent case study created to demonstrate BA and UI/UX method. The client, users and data are fictional, and the KPI baselines and targets are assumptions. Nothing here is client work.

[← All case studies](../README.md)

## Functional requirements

| ID | Requirement | Priority | Story |
|---|---|---|---|
| FR-01 | Add a beneficiary with account validation | Must Have | US-01 |
| FR-02 | Transfer with amount limit check | Must Have | US-02 |
| FR-03 | Search transactions by date, amount or name | Should Have | US-03 |
| FR-04 | One-time code for new beneficiaries | Could Have | US-01 |

## Non-functional requirements

- Pages load in under 3 seconds on a 4G connection
- Text meets WCAG AA contrast and all controls are keyboard reachable
- Session expires after 5 minutes of inactivity
- Sensitive data is masked on screen
